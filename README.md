# new_leads — новые компании без сайта и рассылка им

Находит компании, зарегистрированные в регионе, берёт их контакты, оставляет
тех, у кого нет сайта, складывает в Google-таблицу и рассылает им письма.

## Пять команд

| Команда | Что делает |
|---|---|
| `leads start` | начать прогон сейчас |
| `leads schedule` | прогон **каждый день в 10:00** и при каждом включении Мака |
| `leads stop` | отменить расписание и остановить идущий прогон |
| `leads test` | проверка рассылки: одно тестовое письмо себе |
| `leads send` | рассылка: до 10 писем за запуск |

Больше ничего запоминать не нужно.

**Прогон** берёт компании за последние 60 дней, добирает контакты в Checko
и дописывает в лист «Без сайта» только тех, кого там ещё нет. Колонки
«Статус», «Кто пишет», «Заметки» — ваши, прогон их не трогает. Каждый прогон
оставляет строку на листе «Журнал». Если в 10:00 Мак спал, прогон начнётся,
когда он проснётся.

**Рассылка** сначала шлёт повтор тем, кто молчит 5+ дней (ответом в ту же
цепочку), потом новые письма — всего до 10, с паузой около 4 минут. После
каждого письма компания в таблице получает статус «написали» и дату в
«Заметках». Кому поставили «ответил» или «отказ» в CSV-списке — тем больше
ничего не уходит. При первом `leads test` или `leads send` спросит Gmail,
пароль приложения (хранится в Связке ключей macOS) и адрес для теста.

## Установка (один раз)

Нужен Mac и Python 3.10+.

```bash
git clone https://github.com/amalyshev920-code/new_leads.git ~/new_leads
cd ~/new_leads
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp config.example.json config.json
ln -sf ~/new_leads/leads ~/.local/bin/leads
```

Последняя строка делает команду `leads` доступной из любой папки
(если `~/.local/bin` нет в PATH: `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc`).

Рядом со скриптом должны лечь два секретных файла — их нет ни в репозитории,
ни в архиве, их передают лично:

- `google_key.json` — ключ сервисного аккаунта Google; сам аккаунт должен
  быть редактором таблицы;
- `checko_key.txt` — ключ API Checko (100 запросов в день бесплатно,
  checko.ru/integration/api). Без него контакты берутся со страницы сайта,
  а она быстро начинает показывать капчу.

## config.json

| Поле | Что это |
|---|---|
| `region` | код региона ФНС: 25 Приморье, 77 Москва, 78 СПб, 38 Иркутск… |
| `sheet_id` | id Google-таблицы — часть ссылки между `/d/` и `/edit` |
| `gis_city` | `null` или слаг города 2ГИС (`vladivostok`) — добирать контакты там |
| `mail_dir` | папка со списками рассылки (CSV) |
| `mail_lists` | файлы списков по порядку: из первых письма уходят раньше |
| `sender` | имя в подписи письма |
| `smtp_user`, `test_to` | заполнятся сами при первом `leads test` |

Список рассылки — CSV с колонками `name;reg_date;niche;email;status;sent_at;message_id`.
Ниши: логистика, стройка, архитектура, недвижимость, медицина, образование,
автосервисы, производство, мебель, рестораны. Текст письма — `outreach.py`,
функция `letter()`; проверка сборки — `python3 test_outreach.py`.

## Откуда данные

- **Список компаний** — ЕГРЮЛ (egrul.nalog.ru) перебором ОГРН: с 2022 года
  номера в регионе идут подряд. Rusprofile и прочие справочники скриптам
  отдают 403.
- **Контакты** — API Checko, опционально 2ГИС.
- **«Сайта нет»** — сайта нет в Checko и 2ГИС, а почта на бесплатном домене
  или её домен не открывается.

Ответы кешируются в `cache_<регион>.json`, ход прогона — в `daily.log`.

## Разовая выгрузка в Excel

```bash
.venv/bin/python new_leads.py --region 25 --since 01.09.2026 --until 30.09.2026
```

Флаги: `--all` (без фильтра ниш), `--gis vladivostok`, `--limit 10`, `--out файл.xlsx`.

## Важно

Контакты из открытых реестров — часто личная почта и телефон директора.
Для холодных писем учитывайте 152-ФЗ и ст. 18 закона «О рекламе»: небольшие
волны, честная тема, один повтор и отказ по первому «нет».
