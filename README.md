# new_leads — новые юрлица без сайта

Берёт компании, зарегистрированные в регионе за период, ищет их контакты,
оставляет тех, у кого нет сайта, и кладёт в Excel (+ CSV рядом).

## Установка (один раз)

Нужен Python 3.10+.

```bash
python3 -m venv ~/.venvs/leads
~/.venvs/leads/bin/pip install -r requirements.txt
```

## Запуск

```bash
~/.venvs/leads/bin/python new_leads.py --region 25 --since 01.09.2026 --until 30.09.2026
```

| Флаг | Что делает |
|---|---|
| `--region` | код региона ФНС: 25 Приморье, 77 Москва, 78 СПб, 38 Иркутск, 54 Новосибирск… |
| `--since`, `--until` | период регистрации, ДД.ММ.ГГГГ; внутри одного года. `--until` по умолчанию — сегодня |
| `--all` | не фильтровать по нишам (по умолчанию: медицина, стройка, логистика, производство и т.п. — см. `NICHES` в скрипте) |
| `--gis vladivostok` | тем, у кого Checko пуст, добирать телефон и сайт в 2ГИС (слаг города из адреса 2gis.ru/…) |
| `--limit 10` | пробный прогон на первых N компаниях |
| `--out file.xlsx` | куда сохранить (по умолчанию `~/Desktop/Work/Новые_без_сайта_<регион>_<период>.xlsx`) |

## Ежедневное пополнение Google-таблицы

```bash
~/.venvs/leads/bin/python new_leads.py --region 25 --daily --sheet <id таблицы>
```

Берёт последние 60 дней, перепроверяет в Checko до 20 компаний, по которым
неделю назад контактов ещё не было, и дописывает в лист «Без сайта» только
новых (по ОГРН). Колонки «Статус», «Кто пишет», «Заметки» — для людей,
скрипт их не трогает. Каждый прогон оставляет строку на листе «Журнал».
Нужен ключ сервисного аккаунта `google_key.json` рядом со скриптом, а сам
аккаунт должен быть редактором таблицы.

## Что на выходе

Excel с тремя листами:

- **Без сайта** — готовый список под рассылку: название, ИНН, ОГРН, дата,
  директор, ниша, ОКВЭД, адрес, телефон, почта, пометка «сайта нет»,
  ссылка на Checko. Попадают только те, у кого есть телефон или почта.
- **Все найденные** — все компании периода в нишах, включая тех, у кого
  сайт есть или контакта нет (для статистики).
- **Параметры** — период и сколько отсеялось на каждом шаге.

## Откуда данные и почему не Rusprofile

- **Список** — напрямую из ЕГРЮЛ (egrul.nalog.ru) перебором ОГРН. Rusprofile,
  list-org и checko-поиск отдают скриптам 403/429, а ФНС — нет, и там полный
  список. Начало периода ищется бинарным поиском по дате.
- **Контакты** — карточка компании на checko.ru (телефон, почта, сайт из
  открытых источников). Опционально 2ГИС.
- **«Сайта нет»** — сайта нет ни в Checko, ни в 2ГИС, а почта либо на
  бесплатном домене (mail.ru, yandex…), либо её домен не открывается.

## Что важно знать

- **Скорость**: ~5–10 секунд на компанию (ФНС и Checko нельзя долбить).
  Месяц по Приморью (~170 компаний) — около получаса.
- **Кеш**: ответы копятся в `cache_<регион>.json`. Прерванный или повторный
  запуск продолжает с того же места и не ходит в сеть за уже известным.
- **Свежесть**: у компаний младше 2–3 недель Checko обычно ещё пуст —
  контакты появляются позже. Лучше брать период, закончившийся пару недель назад.
- Контакты из открытых реестров — это часто личная почта и телефон
  директора. Для холодных писем по ним учитывайте 152-ФЗ и 38-ФЗ «О рекламе».
